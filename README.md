# Orange Global Hire - Staffing Portal

![Orange Global Logo](public/logo.png) <!-- Ensure logo exists or remove this -->

A premium, enterprise-grade staffing and recruitment portal built with React, TypeScript, and Tailwind CSS. This platform connects exceptional professionals with world-class organizations, featuring a modern, responsive design and high-end interactive components.

## 🚀 Features

- **Dynamic Hero Section**: High-impact visual introduction with smooth scroll-aware navigation.
- **Enterprise Carousels**: Custom Swiper-based carousels for Services, Industries, and Testimonials with animated progress bars.
- **Advanced Auth Flow**: Standardized split-screen authentication for Employers and Talent.
- **Interactive Forms**: Multi-step registration for talent with resume parsing capabilities (mock implementation).
- **Premium Aesthetics**: Rich UI with glassmorphism, fluid animations (Framer Motion), and professional iconography (Lucide).

## 🛠️ Tech Stack

- **Framework**: [React 18](https://reactjs.org/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Carousels**: [Swiper](https://swiperjs.com/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 📦 Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/SocialOrangeGlobal/OrangeGlobal-Hire.git
   ```

2. **Navigate to the project directory**:
   ```bash
   cd OrangeGlobal-Hire
   ```

3. **Install dependencies**:
   ```bash
   npm install
   ```

4. **Start the development server**:
   ```bash
   npm run dev
   ```

## 🏗️ Project Structure

```text
src/
├── components/     # Reusable UI components
│   ├── layouts/    # Navbar, Footer, etc.
│   ├── sections/   # Major page sections (Hero, Services, etc.)
│   └── ui/         # Base UI elements
├── pages/          # Full page components (Auth, Dashboard)
├── data/           # Static content and mock data
├── hooks/          # Custom React hooks
├── types/          # TypeScript definitions
└── utils/          # Helper functions and animations
```
